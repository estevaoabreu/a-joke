# A Joke

This website was developed for the "Project 3 - Multimedia Applications" course unit of the Bachelor's in Design and Multimedia of the Faculty of Sciences and Technology of the University of Coimbra. This project was made with Alexandra Costa, João Luís Marques and Maria Branco.

The main objective was to develop an interactive experience to serve as an audiovisual representation of Anton Chekhov's A Joke.

## Library Used

**p5.js** <https://p5js.org/>

*p5.js is a friendly tool for learning to code and make art. It is a free and open-source JavaScript library built by an inclusive, nurturing community. p5.js welcomes artists, designers, beginners, educators, and anyone else!*
